# Uplift

The five critical surfaces moved from a pre-pass median of 300 to a post-pass median of 900 (+600). The largest changes were reproducible release staging (+700), model discovery consistency (+600), and installer safety/recovery (+600).

Material behavioral differences:

- one installed binary is now two equivalent packaged command names;
- repository-dependent orientation is now live binary introspection;
- human Clap stderr for robot typos is now one path-free JSON line;
- coarse terminal families are now 13 exact stable error codes;
- model discovery status and execution now use the same resolver;
- the acoustic diarizer is explicitly uncertified rather than described as production-ready;
- doctor readiness is explicitly static preflight, never runtime proof;
- release download failure is terminal instead of silently changing provenance;
- archives and source siblings are authenticated before replacement/build;
- DSR has a proved native artifact path and GitHub Actions are manual fallback only.

No score was awarded for cross-platform artifacts, transcription accuracy, diarization accuracy, or Sortformer promotion because those were not proved here.
